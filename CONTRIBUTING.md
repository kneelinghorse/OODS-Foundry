# Contributing

OODS Foundry is free to use under the Apache License 2.0. This repository mirrors each release and does not accept pull requests; they will be closed. Bug reports and feedback are welcome in [Issues](https://github.com/kneelinghorse/OODS-Foundry/issues).

For a bug, include the package version, operating system, MCP client, the smallest reproducing input, and the expected and actual result. Remove credentials and private data before posting. Send security reports privately as described in [SECURITY](SECURITY.md).
