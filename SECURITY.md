# Security reports

Report a suspected vulnerability privately to derek@derekn.com. Include the affected version, what you found, how to reproduce it and its likely impact. Do not post credentials or private data in a public issue.

For ordinary bugs and feedback, use [Issues](https://github.com/kneelinghorse/OODS-Foundry/issues).

The [package security guide](packages/foundry/SECURITY.md) describes what the local runtime runs, fetches and writes.
