# Harbor example components

A small editable Button package for the OODS Foundry quickstart. It renames `content` to `caption` and `intent` to `appearance` so the mapping performs an actual translation. It uses native button semantics and emits React `onActivate` / Vue `activate`. Both frameworks read the active brand's CSS variables.

Run `npm install --ignore-scripts`, then `npm pack --ignore-scripts`. No build step is required. This package is a local example, not a published component library. Replace it with your implementation and inspect the advisory contract report.
