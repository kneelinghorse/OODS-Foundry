# Security

Report a suspected vulnerability in the OODS Foundry plugin, or in the OODS Foundry MCP server it runs, privately by
email to derek@derekn.com. That address is for security reports only. Include the plugin version, what you found, how
to reproduce it and its likely impact. Do not post an unfixed vulnerability, credentials or private data in a public
issue.

For ordinary bugs and feedback, use [Issues](https://github.com/kneelinghorse/OODS-Foundry/issues).

The plugin's [README](oods-foundry/README.md) describes what it runs, fetches and writes.
